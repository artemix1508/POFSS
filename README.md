# POFSS

**POFSS** - Portable Open Free Software Suite is a software suite distributed under the BSD 3-Clause license.
It's main goal is to create free, open-source programs, whether it's for daily or commercial use.

## We don't ship pre-built binaries - here's why:

1. Having to compile, commit and push binaries into the repository would take a long amount of time. As the project gets bigger the more space it requires.

2. Laziness - Yes, this one is on us, however we want to keep the working tree clean of any non-source code files, which include binaries.

3. You don't have to worry about us never releasing pre-built programs. Once POFSS gets big enough might start separately releasing them!
